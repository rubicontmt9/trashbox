# 🎯 TrashBox - 12 Mini Apps Collection

高速開発された 12 個のミニアプリケーションのコレクション。React + TypeScript + Tailwind CSS で構築。

## 📱 アプリ一覧

### 🎮 ゲーム
- **2048 Game** - クラシックパズルゲーム（矢印キーで操作）
- **Match Game** - メモリマッチングゲーム
- **Typing Master** - タイピング速度テスト

### ⏱️ ユーティリティ
- **Pomodoro Timer** - 作業/休憩セッションタイマー（25分/5分設定可能）
- **Password Generator** - セキュアパスワード生成（カスタマイズ可能）
- **QR Code Tool** - QRコード生成・ダウンロード
- **Calculator** - 高度な計算機（履歴付き）
- **Smart Notes** - ローカルストレージ使用のメモアプリ

### 💰 プレミアム機能
- **Budget Tracker** - 家計管理・カテゴリ分類
- **Habit Tracker** - 習慣追跡・ストリーク表示
- **Task Manager** - タスク管理・優先度設定
- **Weather Dashboard** - 天気情報表示（複数都市対応）

## 🚀 クイックスタート

```bash
# インストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```

## 🛠️ 技術スタック

- **React 18** - UI フレームワーク
- **TypeScript** - 型安全性
- **Tailwind CSS** - スタイリング
- **Lucide React** - アイコン
- **Vite** - バンドラー
